# ROS 2 learning app

Gamified static web app (`index.html`, `app.js`, `style.css`); lessons in `content\`.
Path: Linux, then Python, then turtlesim. ROS 2 Humble runs in WSL.

- Run: open `index.html` in a browser
- Live site: https://danny3929.github.io/ros2-learn/
- Publish changes: run `.\publish.ps1 "message"` (bumps the cache, pushes, waits for the site)
